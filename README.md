# Наруто — щоденник перегляду

Українська шпаргалка для перегляду «Наруто». Статичний сайт без серверної частини та обов’язкових залежностей.

## Можливості

- **Каталог:** 220 серій «Наруто», 500 серій «Шіппудена», 51 серія спінофу про Рока Лі та 10 повнометражних фільмів.
- **Сюжетний маршрут:** 427 серій + The Last, без 293 повністю філерних серій та окремих спінофів.
- Відмітка однієї серії, вибраних рядків, сторінки результатів, усіх результатів, діапазону номерів або сюжетного блоку.
- Зміна статусу в обидва боки й скасування останньої операції.
- Пошук за номером, діапазоном (`25–40`) або аркою; фільтри за типом і статусом.
- Адаптивний інтерфейс, клавіатурне керування, озвучення змін, повага до reduced motion.
- Дві сторінки через `#catalog` і `#story`: працюють на будь-якому статичному хостингу, зокрема в підкаталозі GitHub Pages.

## Локальний запуск

Потрібен Node.js 22 або новіший. Встановлювати пакети не потрібно.

```sh
npm run dev
```

Відкрийте адресу, яку надрукує сервер (типово `http://127.0.0.1:4287`). Інший порт: `PORT=4300 npm run dev`.

```sh
npm test
npm run check
```

Тести перевіряють повноту каталогу, відсутність філерів/дублікатів у маршруті, позицію The Last, перехідні серії, пакетні зміни, скасування, відновлення прогресу та помилки сховища.

## Прогрес

За вибором власника прогрес зберігається в `localStorage` цього браузера, без акаунта. Ключ: `naruto-cheatsheet:progress:v1`. Дані містять версію формату та список стабільних ID. Зміни підхоплюються в інших вкладках цього ж браузера. Перед записом читається актуальний стан.

Прогрес різний для різних адрес сайту; між пристроями не синхронізується. Очищення даних сайту та завершення приватного сеансу можуть його видалити. Помилка читання/запису показується в інтерфейсі; пошкоджені дані не перезаписуються мовчки.

## Джерела й принцип маршруту

Перевірено 22 вересня 2026 року:

- [Anime Filler List: Naruto](https://www.animefillerlist.com/shows/naruto) — 90 повністю філерних серій.
- [Anime Filler List: Naruto Shippuden](https://www.animefillerlist.com/shows/naruto-shippuden) — 203 повністю філерні серії, № 28 позначено як anime canon.
- [Studio Pierrot: Rock Lee](https://pierrot.jp/archive/2010/tv10_05.html) — 51 серія окремого спінофу.
- [The Last: Naruto the Movie](https://en.wikipedia.org/wiki/The_Last:_Naruto_the_Movie) — місце фільму між подіями основної історії та епілогом.

Категорії довідкові: різні фанатські джерела можуть інакше класифікувати змішані серії та адаптації новел. Тут змішані серії залишено, бо вони містять матеріал основного сюжету. Отже, це маршрут **без повністю філерних епізодів**, а не монтаж без кожної філерної сцени. Новели про Ітачі, Саске, Шікамару й фінальний епілог залишено як частину телевізійної історії, а не названо спінофами.

The Last стоїть після «Шіппудена» № 493 і перед № 494–500. Це зручний порядок першого перегляду, а не сувора внутрішня хронологія кожного спогаду. № 141–142 та № 220 «Наруто» залишено заради перехідних сцен; на сайті пояснено, де вони розташовані, без неточних таймкодів.

Решта дев’ять фільмів відмічені як позасюжетні. «Боруто» (аніме й фільм), OVA та короткометражні спецвипуски не включено: шпаргалка завершує телевізійну історію Наруто. Назви арок і фільмів — редакційні українські переклади. У таблиці наведено номери серій та назви арок, а не вигадані офіційні українські назви епізодів.

## Розгортання

Вміст `dist/` — готовий сайт, збірка не потрібна. Відносні посилання дозволяють розмістити його в корені або підкаталозі.

Репозиторій містить workflow `.github/workflows/pages.yml`. Для GitHub Pages оберіть **Settings → Pages → Source → GitHub Actions**, потім запустіть **Deploy to GitHub Pages** або зробіть push у `main`. Workflow не змінює доступ до репозиторію.

`.openai/hosting.json` містить ідентифікатор окремої публікації Sites; секретів там немає. Для власної копії достатньо `dist/` — прив’язка до Sites не потрібна.

## Структура

```text
dist/
  index.html       # Каркас, метадані та навігація
  styles.css       # Адаптивна тема
  data.js          # Каталог, діапазони, маршрут і джерела
  progress.js      # Збереження, пакетні зміни та скасування
  app.js           # Інтерфейс і необов’язковий WebMCP
scripts/serve.mjs   # Локальний HTTP-сервер
tests/             # Тести Node.js
```

У браузерах із WebMCP доступні `get_watch_progress` та `set_episodes_watched`. Вони працюють із тим самим станом та перевірками, що й видимі кнопки. У звичайних браузерах ця можливість просто пропускається.
